## ✅ Accuracy

Saare shortcuts **Google ki official Chrome help page** se verify kiye gaye hain:
[support.google.com/chrome/answer/157179](https://support.google.com/chrome/answer/157179)

Kuch common galat-fahmiyan jo yahan theek ki gayi hain:

| ❌ Galat | ✅ Sahi |
|---|---|
| `Ctrl + ,` se Settings (Windows) | Windows par shortcut nahi — `Alt + F` phir `S`, ya `chrome://settings` (Mac: `⌘ + ,`) |
| `Ctrl + Shift + Esc` = Chrome Task Manager | `Shift + Esc` |
| `Ctrl + Shift + U` = View source | `Ctrl + U` |
| `F3` = agla match | `F3` find bar kholta hai; agla match = `Ctrl + G` |
