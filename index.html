PART 2 — SETTINGS (chrome://settings)

Address bar mein chrome://settings likho. Har section ka apna direct URL bhi hai (neeche diya gaya hai).

1. You and Google — chrome://settings/people

  • Sync and Google services — history, bookmarks, passwords, extensions sab devices par sync.
  • Manage your Google Account — security, 2-Step Verification, My Activity delete karna.
  • Import bookmarks and settings — Firefox/Edge se data laao.

2. Autofill and passwords — chrome://settings/autofill

  • Password Manager — saved passwords, Checkup tab (leak hue password batata hai), passkeys, Windows Hello se protect karna.
  • Payment methods — cards save karo.
  • Addresses and more — address autofill.
  • Enhanced autofill — chaaho to OFF rakho.

3. Privacy and security — chrome://settings/privacy

  • Safety Check — ek click mein sab kuch scan.
  • Delete browsing data — history, cookies, cache, passwords clear.
  • Third-party cookies — "Block third-party cookies" chunna sabse privacy-friendly.
  • Cookies and other site data — allow/block lists manage karo.
  • Security — Standard protection ya Enhanced protection (URLs Google ko bhejta hai, par zyada safe).
  • Ad privacy — Topics, Ad measurement, Ad personalization ko OFF kar sakte ho.
  • Site settings — har site ke liye location, camera, mic, notifications, pop-ups, clipboard, sensors ka control. Notification spam hamesha ke liye yahan se band karo.

4. Performance — chrome://settings/performance

  • Memory Saver — inactive tabs ki RAM free karta hai. Modes: Moderate / Balanced / Maximum + site exceptions.
  • Energy Saver — laptop battery bachata hai.
  • Preload pages (Speed section) — "Extended preloading" ON = pages jaldi khulte hain, thoda data/RAM zyada lagta hai.

5. Appearance — chrome://settings/appearance

  • Theme — Chrome Web Store se custom theme.
  • Customize Chrome — new tab page ka background, colour, shortcuts.
  • Show Bookmarks bar — Ctrl + Shift + B
  • Show Home button — isme apna custom URL daal sakte ho.
  • Font size — Very small se Very large; "Customize fonts" mein exact size + default page zoom.

6. Search engine — chrome://settings/search

  • Default search engine badlo (Google, Bing, DuckDuckGo, YouTube…).
  • Manage search engines and site search — yahan se custom keyword banao: jaise yt type karke Tab dabao to seedha YouTube search.

7. On startup — chrome://settings/onStartup

  • New Tab page / Continue where you left off (sabse useful) / Specific pages kholo.

8. Downloads — chrome://settings/downloads

  • Download location change.
  • "Ask where to save each file before downloading" — ON kar lo.
  • Automatic downloads ki allow/block list.

9. Languages — chrome://settings/languages

  • Spell check, auto-translate, preferred language order, Chrome ka interface language.

10. Accessibility — chrome://settings/accessibility

  • Screen reader support, "Highlight text cursor", Live Caption (video ke live captions).

11. System — chrome://settings/system

  • Hardware acceleration — graphics card use karo (video stutter ho to OFF karke dekho).
  • On-device AI — Chrome local AI models download karta hai; data bachana ho to OFF.
  • Chrome band hone ke baad background apps chalte rahein — yahan se.
  • Chrome ka built-in Task Manager kholo.

12. Extensions — chrome://extensions

  • Installed extensions manage karo; Developer mode ON karke unpacked extension load karo.
  • Har extension ka Site access — "On click" sabse safe.
  • chrome://extensions/shortcuts — har extension ka apna keyboard shortcut banao (bahut kaam ki cheez).

13. AI innovations — chrome://settings/ai

  • Gemini in Chrome, page content sharing, Tab organizer, History search, Compose, Page summarizer — jo nahi chahiye OFF karo.

14. About Chrome — chrome://settings/help

  • Version dekho aur Update karo.
  • Sab kuch default par laana ho: chrome://settings/reset (bookmarks aur extensions safe rehte hain).

PART 4 — PRO TIPS (jo log kam jaante hain)

  1. Tab pin karo — tab par right-click → "Pin". Chhota ho jaata hai aur hamesha rehta hai.
  2. Tab groups — tab par right-click → "Add tab to new group". Colour + naam do, ek click mein poora group collapse.
  3. Vertical tabs (naya) — window ke top par right-click → "Show Tabs Vertically". Zyada tabs ke liye best.
  4. Site ko App banao — 3-dot menu → Cast, save and share → Install page as app. Desktop icon, alag window, bina address bar.
  5. Reading Mode — page par right-click → "Open in reading mode", ya Alt + Shift + R. Full-screen ya side panel, font/colour badalna, aur text ko bolkar sunna bhi.
  6. Split view — Shift + Alt + N se active tab mein split screen.
  7. Khule tabs dhoondhna — address bar mein tab ka title type karo; result ke neeche "Switch to this tab" aayega.
  8. Multiple profiles — top-right avatar se alag Google account/profile (office + personal).
  9. Password checkup — chrome://settings/passwordCheckup — leak hue passwords turant pata chalte hain.
  10. Chrome Task Manager (Shift + Esc) — RAM khaane wala tab pakdo aur end karo.
  11. `Ctrl + Shift + T` sabse life-saving shortcut hai — galti se band hua tab wapas.
  12. Incognito mein extensions default OFF rehte hain — chrome://extensions → extension ki details → "Allow in Incognito" ON karo.
  13. Extension ka apna shortcut — chrome://extensions/shortcuts (jaise "copy page URL" ke liye hotkey).
  14. Chrome reset — chrome://settings/reset.

PART 5 — SPEED UP CHECKLIST

  • Extensions kam rakho (har extension RAM khaata hai) — chrome://extensions.
  • Memory Saver ON + Balanced mode (chrome://settings/performance).
  • Energy Saver ON (laptop par).
  • Preload pages → Extended preloading (fast loading, thoda extra data).
  • Hardware acceleration ON (chrome://settings/system); video stutter ho to OFF karke test karo.
  • Time-time par Ctrl + Shift + Delete → "Cached images and files" clear.
  • chrome://flags ke experimental flags ko default par rakho — galat flag browser crash kara sakta hai.
  • Tab groups + Memory Saver se 30+ tabs bhi smoothly chalte hain.
